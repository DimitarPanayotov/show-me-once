# Demo video outline (maximum 5 minutes)

Record the browser at readable zoom. Use only public search terms and a disposable test account. Hide the password during sign-in and keep the address bar visible for result pages.

| Time | Show |
| --- | --- |
| 0:00–0:25 | The web library and unpacked Chrome extension. State the one-demonstration-to-reusable-skill goal. |
| 0:25–1:15 | Record a Wikipedia search, stop, show the sanitized timeline, generate `SKILL.md`, and point to the parameter and navigation checkpoints. |
| 1:15–2:10 | Run that skill with two different topics. Show one explicit confirmation and the resulting page after each run. |
| 2:10–3:05 | Show GitHub repository filtering with `actions` and `docs`, then Open Library title searches with `Foundation` and `Frankenstein`. Short cuts can skip the repeated intermediate clicks, but show the run log and final URL for each input. |
| 3:05–4:00 | Save a skill to the library, edit it into a second version, and share it with another test account. Show that the recipient can load it. |
| 4:00–4:35 | Show the per-step run history, the Stop control, and the absence of parameter values in the log. |
| 4:35–4:55 | Show the architecture note and GitHub repo URL. |

The personal report required by the take-home should be written separately by the candidate in their own words.
