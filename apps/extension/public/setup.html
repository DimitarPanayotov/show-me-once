Show Me Once · Getting started

Connect once.
Then just ask your agent.

Record a browser task, then let your existing coding agent repeat it with new inputs. Chrome shows the actions and asks for approval when needed.

1. Connect your agent

You need Chrome, Node.js 24, and a local coding agent. Codex is the configured example. Use the supplied reviewer kit; there is no server window to keep running.

  1. At chrome://extensions, turn on Developer mode, choose Load unpacked, and select the kit's extension folder. Pin Show Me Once to the toolbar.
  2. Open the extension → Connect your coding agent and choose Copy ID.
  3. In the kit's connector folder, open Connect with Codex.cmd on Windows. On macOS/Linux, run node setup.mjs there. Paste the extension ID. Choose Codex to register the connection automatically.
  4. Restart/reconnect Codex so it loads the new connection. Return to the extension and paste the pairing code printed by setup. Choose Connect coding agent.

✓ Connected to your coding agent confirms success. Close the setup window. Your agent manages the connection from now on; pairing is remembered.

The pairing code is private. Paste it only into the extension, never into an agent conversation.

2. Try a complete example

  1. In Skills & activity, choose Open Wikipedia & copy example request.
  2. On Wikipedia, choose English as the search language.
  3. Paste the copied request into your coding agent. It discovers and reads the example automatically; no skill-file installation is needed.
  4. Watch the browser. When approval is requested, open the extension, review the search action, and confirm. If the agent ended its reply while waiting, tell it: I approved in the extension. Continue the same run.
  5. Verify the Grace Hopper result and completed activity. Return to Wikipedia's starting page and ask for Alan Turing using the same skill.

3. Teach your own task

  1. Open the task's starting page. In Record, choose Start recording.
  2. Do the task once, then choose Stop & create skill.
  3. Review its name and choose Use with agent. Open the starting page again and copy the request into your agent. It will ask for new inputs.

Pause, Resume, and Stop stay in the extension. You can close the popup while the agent works.

No library account is needed for the example or local recordings. Sign in when you want cloud saving, versions, or sharing. Markdown and skill ZIP exports are optional.

Other coding agents and manual configuration

Use a local client that supports MCP over stdio. In setup choose the manual option. Configure the server with command node and the absolute path to connector/server.mjs as its argument. Reconnect the client and verify seven tools, including list_skills and get_skill. Other clients have not been verified end to end.

If something does not connect

Confirm Node.js 24 and the correct extension ID. Reconnect your agent, then use Check connection in the extension. If upgrading, close an old manually started connector once. Use Forget connection only to remove pairing. Never run a second helper to fix a lost connection.

A changed page, a human-verification screen, or an uncertain action pauses the run. Inspect the page before continuing; Stop and start again if the connection identity changed.

Verification: the protocol and controller have automated coverage. A real connected coding-agent/Chrome acceptance run of this version is still required before claiming the demo is verified.
